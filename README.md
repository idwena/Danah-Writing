# ديوان دانة

موقع شخصي للقصائد والكتابات، بستايل آلة كاتبة كلاسيكي. HTML و CSS فقط، ما يحتاج أي تثبيت.

## الملفات

```
├── index.html      ← الرئيسية (صورة الآلة الكاتبة، قصيدة مختارة، أحدث القصائد والكتابات)
├── poems.html      ← كل القصائد
├── writings.html   ← الخواطر والنثر
├── about.html      ← عنّي وروابط التواصل
├── css/style.css   ← كل التصميم
├── js/main.js      ← حركة الكتابة وظهور الأقسام
└── img/            ← الصور
```

## كيف تعدّلين

1. **قصيدة شعر حر**: في `poems.html` انسخي `<article class="piece">` اللي فيه `<p class="verse">` واكتبي القصيدة كما هي، وكل سطر جديد يطلع سطر جديد.
2. **قصيدة عمودية**: استخدمي `<div class="abyat">`. كل بيت يكون في `<div class="bayt"><span>الصدر</span><span>العجز</span></div>`.
3. **الخواطر**: في `writings.html` كل نص في `<article>`، وكل فقرة في `<p>`.
4. **الصفحة الرئيسية**: بدّلي القصيدة المختارة والبطاقات في `index.html`. رابط كل بطاقة يوديك للقصيدة نفسها (مثل `poems.html#poem-1`)، فخلّي `id` القصيدة نفس الرابط.
5. **عنّي**: في `about.html` بدّلي النبذة، والإيميل، وروابط إنستغرام وإكس. ولو تبين صورتك حطيها في `img` وغيّري `src`.
6. **الألوان والخطوط**: كلها في أول `css/style.css` تحت `:root`.

## النشر مجاناً على GitHub Pages

من إعدادات المستودع: **Settings ← Pages**، اختاري فرع `main` والمجلد `/ (root)` واحفظي. بعد دقيقة أو دقيقتين يصير الموقع على `https://idwena.github.io/Danah-Writing/`.
