# ديوان دانة

موقع على شكل ديوان حقيقي: غلاف من الجلد بزخرفة ذهبية، ينفتح على صفحتين متقابلات، والقارئ يقلّب الصفحات. HTML و CSS وملف جافاسكربت صغير، وما يحتاج أي تثبيت.

## الملفات

```
├── index.html      ← الديوان كله: الغلاف وكل الصفحات
├── css/style.css   ← التصميم (الألوان والخطوط في أوله تحت :root)
├── js/book.js      ← تقليب الصفحات، والفهرس، وأرقام الصفحات
└── img/            ← الصور
```

## كيف تضيفين صفحة

كل صفحة في `index.html` تكون `<section class="page"> … </section>`، وترتيبها في الملف هو ترتيبها في الديوان. **أرقام الصفحات والفهرس تنحسب تلقائياً**، فما تحتاجين تعدّلينها بيدك.

- **قصيدة شعر حر**: انسخي صفحة «القصيدة الأولى» واكتبي القصيدة داخل `<p class="verse">` كما هي، وكل سطر يطلع في سطر.
- **قصيدة عمودية**: انسخي صفحة «القصيدة الثانية». كل بيت يكون `<p class="bayt"><span>الصدر</span><span>العجز</span></p>`.
- **خاطرة أو نص**: انسخي صفحة «عنوان الخاطرة»، وكل فقرة في `<p>`.
- **باب جديد**: انسخي صفحة «الباب الأول» وغيّري `data-part` (اسم الباب اللي يطلع أعلى صفحاته).

خصائص تحطينها على الصفحة:
- `data-toc="العنوان"`: تطلع الصفحة في الفهرس بهذا الاسم.
- `class="page center"`: المحتوى في نص الصفحة (حلو للقصائد القصيرة).
- `class="page plain"`: صفحة بدون رقم وبدون عنوان أعلاها.

لو طالت القصيدة عن الصفحة، تقدرين تقسمينها على صفحتين، والثانية بدون `data-toc` حتى ما تتكرر في الفهرس.

## للقارئ

- يفتح الديوان بالضغط على الغلاف.
- يقلّب بالأزرار تحت، أو بالضغط على طرف الصفحة المطوي، أو بالأسهم في الكيبورد، أو بالسحب على الجوال.
- كل صفحة لها رابط، مثل `index.html#p6`، فتقدرين ترسلين لأحد قصيدة معيّنة.
